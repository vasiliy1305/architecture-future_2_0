# Task4Advanced

## Состав артефактов

- `bounded-contexts.md` — описание bounded contexts и границ доменов компании «Будущее 2.0».
- `event-storming.md` — текстовое описание Event Storming и логики взаимодействия доменов.
- `event-storming.puml` — исходник диаграммы Event Storming в PlantUML.
- `event-storming.png` — визуализация Event Storming для ревью.
- `aggregates.md` — описание агрегатов, их границ, инвариантов и ключей.
- `events.md` — каталог доменных событий, контекстов-источников и минимальных контрактов.
- `justification.md` — обоснование перехода к событийной архитектуре и поэтапной миграции от Camel/DWH к событийной платформе.

## Что отражено в решении

В решении показаны:
- bounded contexts и границы доменов;
- ключевые агрегаты внутри доменов;
- основные команды и доменные события;
- политики реакции на события;
- read models для self-service аналитики и переходного legacy-моста;
- поэтапная миграция от текущей интеграции через Camel и DWH к целевой событийной архитектуре;
- отдельные исходный и визуальный артефакты Event Storming для проверки ревьюером.
