# План управления рисками

| Риск | Меры снижения | Подход |
|---|---|---|
| Ошибки при миграции с legacy-систем | Поэтапная миграция, parallel run, fallback-сценарии, контрактные тесты | Технический + управленческий |
| Недостаток компетенций команды в новых технологиях | Обучение, менторинг, пилотные внедрения, внешняя экспертиза | Управленческий |
| Сбои интеграции новых источников данных | Единый integration layer, схемы данных, retry/idempotency, мониторинг интеграций | Технический |
| Утечка данных или ошибки в разграничении доступа | RBAC, audit log, шифрование, secrets management, security review | Технический |
| Сопротивление изменениям со стороны бизнеса и команд | План коммуникаций, выделенные owners, демонстрация быстрых результатов | Управленческий |
